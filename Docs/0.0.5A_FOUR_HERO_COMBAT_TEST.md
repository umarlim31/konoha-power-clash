# KONOHA: POWER CLASH — 0.0.5A Four Hero Combat Foundation

## Source
Branch: `feature/v0.0.5a-four-hero-combat`

Expected footer:
`0.0.5A | Four Hero Combat Foundation`

## Scope
This is the first Phase-2 gameplay-prototype combat batch. It keeps the proven 0.0.4A Rebut Kursi loop and adds the first multiplayer implementations of:

- MEGA — Bull Swing / Banteng Charge / Kader! / Moncong Putih
- PRABOWO — Commander Fist / Commander Leap / Baris! / Garuda Mode
- ABAH — Word Wave / Narasi / Electric Dash / Pidato Kebangsaan
- JOKOWI — Construction Hammer / Infrastruktur / Blusukan / Proyek Nasional
- PENGARUH resource, 0–100
- Hero selection before match/rematch
- Hero-specific Basic tuning
- Hero S1/S2 cooldown UI
- Ultimate availability at 100 Pengaruh
- Silence and Stun runtime states
- Knockback resistance support
- Shield support
- Team movement zones
- Hero-specific greybox ability FX

## Prototype Notes
Numbers in 0.0.5A are validation values, not final balance.

Hero selection cycles:
MEGA -> PRABOWO -> ABAH -> JOKOWI -> MEGA

Default assignment uses client ID modulo four, but every local player may change hero while the match is WAITING or at RESULT.

## Greybox validation tools
Host-only:
- TEST TIMER 10s
- TEST POWER 95
- TEST ULT 100

TEST ULT 100 grants all spawned heroes full Pengaruh so Ultimate behavior can be tested in one short device session.

6. Start match.

- four hero selections replicate,
- Basic/S1/S2/ULT execute authoritatively across two Android devices,

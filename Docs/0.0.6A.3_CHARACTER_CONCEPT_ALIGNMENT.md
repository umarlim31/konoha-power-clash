# 0.0.6A.3 — Character concept alignment

Base: `feature/v0.0.6a2-hero-greybox-polish` at `77ea424`. This is a continuation of the 4v4 networked prototype, not a return to the 0.0.1 offline spike. The existing scene, combat mechanics, netcode, bots, and chair rules remain on this branch.

## Implemented

- Player-facing nameplates, hero HUD, and match feed now use **MEGA, GEMOY, ABAH, PAK WI**. The internal `PrototypeHero` enum retains its numeric values and legacy member names so replicated hero IDs and current gameplay logic do not change.
- Greybox accent materials now follow the submitted concept colors: Mega red, Gemoy warm red, Abah green, Pak Wi red. Team ownership still uses the separate cyan/orange ring and labels.
- The runtime no longer paints every accessory the same accent color. Original dark fabric, light trim, metal, and accent colors survive hero selection; the knockout visual temporarily dims each part from its own source color.
- Added simple procedural shapes to distinguish Mega's long textile silhouette, Gemoy's commander cape, Abah's staff, and Pak Wi's drape at gameplay distance. These remain placeholder primitives, not the 2D character sheets turned into 3D models.

## Visual assessment and next design gate

The submitted sheets give each hero a readable thematic direction, but they also include close likeness/reference images and small decorative detail that may not survive a mobile top-down view. The currently generated 3D heroes are still basic silhouettes; no rigged characters, character animation, facial model, or texture atlas is in the repo. Test silhouettes on a phone at match camera height before freezing any design.

The arena reference proposes a central monument, flank routes, covers, water and institutional buildings. The existing 0.0.6A.2 generator already has a central chair, lanes, flank cover, team spawns, and lighting. The now-reviewed Game Concept Bible v2 separates this existing **Rebut Kursi 4v4** mode from the new solo-first **Jalur Takhta** PvE campaign. The institutional access layers belong to the campaign. Do not insert them into the current 4v4 chair rules merely because they share a landmark. The campaign MVP has Gerbang Rakyat, Majelis Daun, Biro Prosedur, and Istana Takhta, then expands to Komisi Suara, Konsorsium Modal, and Menara Narasi after the first loop works. See `Docs/GAME_BIBLE_V2_IMPLEMENTATION.md`.

# PohonTrembesi

Original low-poly 3D asset for Negara Konoha.

Visual direction: fictional Indonesia/Nusantara/IKN-inspired worldbuilding, without copying a real building, official emblem, party logo, or institution logo 1:1.

- Triangle limit: 20,000
- Actual triangles: 3,400
- Intended instances in map: 4
- Format: OBJ + MTL
- Unit: meter
- Up axis: Y
- Intended forward in Unity: +Z
